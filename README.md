📚 Study Planner – Student Productivity Web App

A simple and interactive web-based study planner developed using HTML, CSS, and JavaScript. This application helps students organize their study schedules, manage academic tasks, set goals, and track their daily progress efficiently.

The goal of this project is to make students' daily study activities more organized and productive.

✨ Features

- 📅 Daily & Weekly Timetable – Organize and manage study schedules.
- 📝 To-Do List – Add and manage subject-wise tasks and assignments.
- ⏰ Reminders – Set reminders for important study activities.
- 🎯 Goal Setting – Set academic goals and monitor progress.
- ✅ Task Tracking – Track completed and pending tasks.

🛠️ Tech Stack

Technology| Purpose
HTML5| Structure of the application
CSS3| Styling and responsive design
JavaScript| Functionality and interactivity

Development Tools:

- Visual Studio Code
- Git & GitHub

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone this repository:
   
   git clone https://github.com/Vinuthna-Toleti/Smart-study-planner

2. Open the project folder in Visual Studio Code.

3. Open the "index.html" file in your browser.

🎯 Project Objective

To develop a user-friendly study management application that helps students plan their academic activities, stay organized, improve time management, and achieve their learning goals.
